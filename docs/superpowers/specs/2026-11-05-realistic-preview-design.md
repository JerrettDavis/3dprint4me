# Realistic customizer preview

Approved scope: the user's “knock it out” executes the Model / Realistic preview description in chat.

Use the existing local Three.js viewer to show configured geometry on a warm tabletop with soft shadows and material lighting. All six generators get an accessible toggle independent of front/back/3D views. Realistic mode uses perspective and hides the print bed and picking highlights; switching back restores editing controls. Settings changes refresh the preview, with pending and failure messages rather than silently showing stale geometry. No external assets, services, images, tracking, persistence or sensitive-value transmission.

Separate presentation-only worker builds are lazy for pumpkin and display sign: assemble loose product parts and omit pumpkin break-away face supports without modifying the downloadable model, parameters, metrics, metadata or hand-off. Ordinary generators reuse exact print meshes. Presentation output contains only geometry and colors, never a downloadable file. Realistic images are illustrative: actual material and print finish vary.

Builder choices: procedural local studio environment and subtle tabletop grain; on-demand WebGL frames; mobile-friendly toggle below the main toolbar; preserve existing themes, reduced motion, offline operation and WebGL fallback. Existing generated catalog images are inspiration, not substitutes for a customer's configured product.
